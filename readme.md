# Love2D Luau Integration
This is an experimental integration of [Luau](https://github.com/luau-lang/luau) into [Love2D](https://github.com/love2d/love).

## How can i use this?
Don't. Half of the required code adjustments were done by claude code. A lot of things may not work. Also i haven't gotten the Luau VSCodium integration to correctly work with the module/loading pattern used by Love2D, so this integration is useless
for me currently.

## Why does this exist?
Mostly because i want to have my own types that i can declare (for example for function parameter) so that i have a better developer experience in IDEs.
